# Material Icons

Google Material Design Icons, rounded 24px SVGs, licensed under Apache-2.0.

Source: https://github.com/google/material-design-icons
License: [Apache License 2.0](material-icons-LICENSE.txt)

Unmodified visible SVG path data is extracted into src/components/icons/material-arrow-paths.json and rendered with currentColor by MaterialArrow. Transparent canvas paths are omitted.
